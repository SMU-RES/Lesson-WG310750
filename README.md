# 单片机及接口技术（WG310750）

本仓库为上海海事大学自动化专业“单片机及接口技术”核心课程的归档资料，包含 7 项课后作业完整 C 源码、期末考试真题试卷（B 卷）、基于 NixOS Flake 与 xmake 的现代化交叉编译构建环境，以及嵌入式 IDE 开发配置。

- **课程代码**：`WG310750`
- **课程属性**：专业必修课，3 学分（大三上学期修读）
- **授课教师**：李佳芮老师
- **硬件平台**：国信天长 蓝桥杯单片机/嵌入式实训开发板（IAP15F2K61S2 / STM32）

## 课程修读与避坑指南（学长实战经验）

### 1. 课程考核与学分演进
- 21、22、23 届为闭卷笔试**考试课**（本仓库在 `references/` 附有 2023 年期末考试真题 B 卷）；
- 据悉自 24 届起改为**考察课**，学分相应减少，考核重心更加偏向平时上机实验与作业验收，难度相应降低。

### 2. 开发环境与编译工具链
- **推荐工具链**：
  - 本项目不仅适配传统 Keil5 开发环境，更推荐使用现代轻量化开源工作流：**VS Code + Embedded IDE (EIDE) 插件 + SDCC 交叉编译器**；
  - 仓库内附完整的 `flake.nix` 与 `xmake.lua`，在 Linux / WSL 环境下可直接通过 `nix develop` 进入预装 SDCC 工具链的开发环境，一键构建固件二进制。

### 3. 硬件开发板避坑提示
- 实验室统一分发的开发板使用年限较久，硬件存在个体差异；
- 部分板子存在 **Micro-USB 烧录口接触不良**、按键机械弹性老化或板载蜂鸣器驱动电平异常（同样的代码在个别板子上蜂鸣器不发声或常鸣）；
- 实验前务必尽早插电脑测试固件烧录与串口握手，尽量挑选成色和接口完好的板子。

### 4. 教师考勤与课堂
- 授课教师为李佳芮老师，平时考勤抓得较为频繁；
- 经常进行纸质名单点名或现场签到，注意保持良好出勤记录。
